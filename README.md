# shearbyte

Shear digests and byte fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/shearbyte/

## Install / run

```bash
git clone https://github.com/theworker02/shearbyte.git
cd shearbyte
node src/cli.js
node --test
```
